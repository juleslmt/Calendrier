Un Noël rien qu'à nous
✦ ❄ ✦

24 jours, juste pour toi

Derrière chaque petite porte se cache un morceau de nous, une pensée, un sourire ou une surprise. Ouvre-en une chaque jour, jusqu'à Noël. ❤️

Le mode découverte permet de tester les 24 surprises. Il devra être désactivé avant d'envoyer le calendrier. Cette première version masque les surprises futures dans l'interface, sans les protéger contre l'inspection du code.

Fait avec amour, pour toi ♡
